# RVCE CONNECT — Full Frontend Prototype

A multi-role campus information and assistance platform prototype based on the agreed RVCE CONNECT requirements.

## Included roles
- Student
- Information Provider / Senior
- Admin

## Included public areas
- Animated 3D RVCE intro using `public/assets/rvce-logo.glb`
- Central campus search
- Search results and detailed information pages
- Verification states: Verified / Needs verification / Outdated
- Departments and offices
- Events
- Hackathons
- Activity Points
- Messages
- Notifications
- Reports and information requests
- Student profile
- Login with role selection

## Student portal
- Student dashboard
- Saved information
- Registered events
- Activity points
- Reports / requests
- Messages
- Notifications
- Profile

## Information Provider / Senior portal
- Provider dashboard
- Assigned information records
- Add information form
- Verification workflow
- Events management
- Student messages
- Provider profile
- Student ID / graduation year / access end-date concept

## Admin portal
- Admin dashboard
- Users
- Providers
- Information
- Departments
- Offices
- Events
- Hackathons
- Activity Points
- Reports
- Messages
- Categories
- Settings
- Audit Logs

## Demo login
The login screen shows the demo credentials for each role. This is a frontend prototype; authentication and database persistence are not connected to a real backend yet.

## Important
All campus records in this prototype are explicitly marked:
`DEMO DATA — NOT OFFICIAL RVCE INFORMATION`

## Run
```bash
npm install
npm run dev
```
